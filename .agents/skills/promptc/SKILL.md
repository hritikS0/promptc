# promptc Skill

Use `promptc` to automatically transform rough developer prompts into structured, production-ready AI specifications.

## Workflow

1. Run `promptc` with the user's input:
   ```bash
   promptc "<user raw prompt>"
   ```
2. Use the output structured JSON or rendered prompt (Objective, Requirements, Constraints, Acceptance Criteria, Setup commands) to carry out the coding task.
